# Kermit Vestal — Professional Portfolio

Source for [kermitv.github.io](https://kermitv.github.io/), my professional introduction and selected public work.

My background spans enterprise application support, SQL, integrations, systems engineering, and automation. The site features [SignalForge](https://github.com/kermitv/signalforge), a public example of deterministic systems design, engineering governance, testing, and AI-assisted development.

## Site structure

- `index.html`: professional introduction and featured project
- `_config.yml`: site metadata and author information
- `_data/navigation.yml`: navigation links

The site is built with Jekyll and hosted on GitHub Pages.
